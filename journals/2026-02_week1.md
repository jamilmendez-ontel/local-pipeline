## Wednesday, February 4, 2026

### Schema Reorganization

Reorganized all tables into proper PostgreSQL schemas for better organization.

**New schema structure:**
```
data_raw/          (raw JSONB tables)
data_staging/      (transformed tables)
reference/         (lookup tables)
pipeline/          (tracking tables)
```

**Migration:** `008_create_schemas.sql`

**Why data_raw/data_staging instead of raw/staging?**
The `raw` and `staging` schemas already existed and were owned by `supabase_admin`. Created new schemas that `postgres` can manage.

### Timezone Standardization

Fixed timezone handling across all transforms.

**Problem:** `datetime.fromtimestamp()` without timezone could shift dates incorrectly.

**Solution:** All conversions now explicitly use America/New_York:
```python
from zoneinfo import ZoneInfo
TZ_ET = ZoneInfo("America/New_York")
```

### CSV Parsing Fix

Fixed critical bug in QA Forms extraction.

**Problem:** Swift API returns CSV headers only on first page. Subsequent pages had no headers, causing `csv.DictReader` to corrupt 97% of data.

**Solution:** Save fieldnames from first page and reuse for subsequent pages.

**Impact:** Fixed ~330,000 corrupted QA records.

### Batch Delete for Large Tables

Fixed out-of-memory errors when clearing large tables.

**Problem:** Deleting 2.2M rows in one query caused PostgreSQL OOM error.

**Solution:** `batch_delete_table()` method deletes in 50,000 row chunks:
```python
while current_id <= max_id:
    client.delete().gte('id', current_id).lt('id', end_id).execute()
    current_id += batch_size
```
